# MWAS Beauty Parlour Website

A responsive blue, white and pink website for MWAS Beauty Parlour, Nakuru.

## Publish on GitHub Pages
1. Create a GitHub repository.
2. Upload everything inside this folder (index.html, styles.css, script.js, and assets).
3. In GitHub: Settings -> Pages -> Deploy from a branch -> main -> / (root).
4. Save and open the Pages URL.
